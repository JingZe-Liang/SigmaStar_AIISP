# GitHub Publication Cleanup Design

## Goal

Prepare `raw_fusion_distill_v2` for GitHub as a self-contained, data-first
V2 source repository with concise documentation and a small, inspectable set
of baseline results.

## Repository Boundary

The repository contains source code, tests, checked-in configurations,
documentation, and curated evidence only. It does not contain source RAW
datasets, MOG2 caches, complete inference arrays, transient checkpoints, log
directories, or generated bytecode.

Runtime-derived data remains outside the repository at
`/data1/wangzepu/Jaime/Projects/DERIVED/v2_data_first`. Documentation uses
that directory as the default output location for new experiments.

## Source Cleanup

Keep the data-first V2 path: input contracts, dataset loading, MOG2-only
supervision, cache generation, sampler, model, selector, range-limited fusion,
training, inference, comparison, CLI, and their tests.

Remove dead Formal V2 remnants that have no active imports or CLI surface,
including the former composer and tiled inference modules, obsolete Formal
schema entries, and historical implementation-plan documents. Retain only
shared artifact and schema utilities that are required by the current dataset,
checkpoint, or cache code.

## Documentation

Replace the stale README with current install, validation, cache, train,
resume, inference, and comparison commands. Add:

- `docs/protocol.md`: model inputs, MOG2 supervision-only boundary, training
  flow, deployment flow, q selection, and range protection.
- `docs/results.md`: provenance and metrics for the current safe-q baseline,
  including its 645x all-zero-q limitation.

No document claims visual quality improvement or a complete solution for 645x.

## Curated Results

Create `results/2026-08-26-safe-q/` from the external DERIVED run. Include the
final baseline checkpoint, its manifest and metrics, comparison summary,
inference traces, and the fixed-ISP 128x triptych video. Do not include RAW
arrays, MOG2 masks, intermediate checkpoints, duplicate balanced-run results,
or smoke outputs.

The checked-in result is explicitly labeled a reproducibility baseline, not a
production model: its 645x q map is zero under the current supervision policy.

## Git Policy and Verification

Update `.gitignore` to reject generated artifacts by default while allowing
only the curated `results/` evidence. Verify with the full unit suite in
`aaa_312`, byte-compile source, check the working tree, and inspect the final
tracked file list and result sizes before handoff.
