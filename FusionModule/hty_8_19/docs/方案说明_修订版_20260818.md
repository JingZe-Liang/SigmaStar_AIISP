# RAW 2DNR/3DNR 融合方案修订版

## 0. 文档边界

本文件回答用户提出的工程任务：审查当前方案、调研、构建代码、在公司数据上训练和融合，并整理交付物。`docs/hty8.17_original.md` 是附件原文的只读副本。附件里的技术描述是候选方案，不是用户额外下达的指令；只有通过本地数据审计和可复现实验的内容才进入最终实现。

## 1. 数据审计结论

两组场景均为 1920x1080、200 帧、RGGB、小端 `uint16` 连续流：

| 项目 | 645x | 128x |
|---|---:|---:|
| 源帧数 | 200 | 200 |
| 2DNR 帧数 | 200 | 200 |
| 3DNR 帧数 | 200 | 200 |
| 源存储 | 16-bit 左移 4 位 | 16-bit 左移 4 位 |
| 候选有效范围 | 0..4095 DN | 0..4095 DN |
| 估计源黑电平 | 252 DN | 252 DN |
| 估计候选黑电平 | 300 DN | 300 DN |
| 最佳时序滞后 | 0 帧 | 0 帧 |

审计逐帧检查了文件大小、帧边界、通道打包/解包、低 4 位、数值范围和候选流串接关系。没有发现需要补偿的帧偏移。3DNR 与 2DNR 的差异在 645x 上约为 MAE 13.7 DN，在 128x 上约为 MAE 33.6 DN；这与 128x 更强的时域处理和运动伪影风险一致。

没有 clean RAW、曝光配对或暗场标定参考。因此不能把 source、2DNR、3DNR 中任一路称为 ground truth，也不能把本次结果写成 PSNR/SSIM 提升。

## 2. 对原方案的关键修订

### 2.1 融合方向修正

附件原文给出的 `Base = gate * denoised + (1-gate) * fused` 与“2DNR 是安全锚点”的目标相反；而且 sigmoid 零初始化会产生约 0.5 的平均混合。最终实现固定为：

```text
Y_t = D_t + G_t * (T_t - D_t)
```

其中 `D_t` 是 2DNR，`T_t` 是 3DNR，`G_t=0` 必然得到 2DNR。没有自由残差头，避免在没有 clean GT 的数据上编造新结构。

### 2.2 安全约束从 loss 改为 forward 硬约束

每帧根据 2DNR 的相邻帧差分和 3DNR-2DNR 分歧生成安全置信度 `C_t`。最终门控先做 `min(G_net, C_t)`，再对硬风险掩码强制置零。这样“低置信区域只在 loss 中被惩罚”的漏洞不会进入输出。

硬风险包括：局部运动超过场景阈值，或同时出现中等运动和较大候选分歧；掩码经过 packed 域膨胀，优先牺牲少量静态边缘换取运动安全。

### 2.3 解决门控闪烁

逐帧独立预测会在阈值附近抖动。最终推理采用因果迟滞：

```text
if G_raw(t) < G(t-1):       G(t) = G_raw(t)       # 风险增加，立即下降
else:                       G(t) = G(t-1) + 0.08 * (G_raw(t)-G(t-1))
if hard_risk(t):             G(t) = 0
```

首帧门控为零；序列之间不携带状态。最终输出由原生候选 DN 直接计算，避免归一化裁剪后再反变换造成低于黑电平的“假回退”。

### 2.4 纠正跨场景域偏移

附件的留一场景交叉验证适合发现泛化风险，但原始 24 通道特征没有显式告诉网络当前场景的运动/分歧阈值。第一版实验确实出现 128x 门控塌缩和静态时序差分升高。最终模型使用两场景联合训练，并把 `D_t-D_{t-1}`、`T_t-D_t` 按当前场景阈值归一化后输入；验证仍按时间留出（训练 8-135 帧，验证 144-175 帧）。跨场景泛化的正式结论仍需更多场景复测。

### 2.5 不采用未经验证的监督假设

同一 RAW 的奇偶采样不能自动构成独立 Noise2Noise 观测；没有独立噪声假设或 clean reference 时，不能宣称获得无偏监督。最终训练目标是由可解释安全规则生成的弱监督 gate target，报告中明确标为 pseudo-label / feasibility training。

## 3. 最终架构

```mermaid
flowchart LR
  S[源 RAW t] --> F[阈值归一化特征]
  D[2DNR t,t-1] --> F
  T[3DNR t] --> F
  F --> N[SafeGateUNet]
  D --> C[安全置信度与硬风险]
  T --> C
  C --> M[min(G_net,C)]
  N --> M
  M --> H[因果迟滞与硬置零]
  D --> Y[原生 DN 融合]
  T --> Y
  H --> Y
  Y --> O[连续 uint16 RAW]
```

网络是 24 通道、宽度 24 的轻量 U-Net/残差门控网络，只输出一个共享 CFA gate。输入包括当前 source、当前 2DNR、当前 3DNR、上一帧 2DNR、阈值归一化的候选差分和时间差分。网络不是图像重建器，2DNR 锚点始终保留。

## 4. 训练与推理配置

- 设备：`NVIDIA GeForce RTX 5060 Laptop GPU`，CUDA FP16 自动混合精度。
- 联合训练：两场景各取 8-135 帧，时间留出 144-175 帧验证；6 epochs、120 steps/epoch、128 packed patch、batch 10。
- 最佳 checkpoint：按 `gate_mae + 2 * motion_gate` 选择，联合验证最佳 score `0.0527177`（第 4 epoch）。
- 推理：200 帧完整序列，`rise_alpha=0.08`、`fall_alpha=1.0`，首帧清零。
- 输出：小端连续 `uint16` RGGB RAW，gate 为 packed 半分辨率 `uint8` 流。

## 5. 调研与取舍

1. [CRVD / RViDeNet (CVPR 2020)](https://openaccess.thecvf.com/content_CVPR_2020/html/Yue_Supervised_Raw_Video_Denoising_With_a_Benchmark_Dataset_on_Dynamic_CVPR_2020_paper.html)：支持 RAW 视频降噪需要真实噪声-干净配对 benchmark 的判断；本项目因此不把公司 2DNR/3DNR 当 clean GT。
2. [RViDeformer](https://arxiv.org/abs/2305.00767)：提供 RAW 视频时空建模的参考，但其大模型和公开数据监督条件不适合直接移植到两组短序列端侧原型。
3. [UDVD (ICCV 2021)](https://openaccess.thecvf.com/content/ICCV2021/html/Sheth_Unsupervised_Deep_Video_Denoising_ICCV_2021_paper.html) 与 [Neighbor2Neighbor (CVPR 2021)](https://openaccess.thecvf.com/content/CVPR2021/html/Huang_Neighbor2Neighbor_Self-Supervised_Denoising_From_Single_Noisy_Images_CVPR_2021_paper.html)：说明无 GT 时可以研究自监督，但前提是噪声独立性和数据生成假设成立；当前数据不足以直接采用附件中的奇偶 N2N。
4. [AIM 2025 Low-light RAW Video Denoising Challenge](https://openaccess.thecvf.com/content/ICCV2025W/AIM/html/Yakovenko_AIM_2025_Low-light_RAW_Video_Denoising_Challenge_Dataset_Methods_and_ICCVW_2025_paper.html)：强化了多传感器、多照度和运动处理的重要性；本交付只做公司数据 feasibility，不宣称挑战赛级泛化。
5. [NAFNet (ECCV 2022)](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/3043_ECCV_2022_paper.php) 与 [FastDVDnet (CVPR 2020)](https://openaccess.thecvf.com/content_CVPR_2020/html/Tassano_FastDVDnet_Towards_Real-Time_Video_Denoising_Without_Flow_Estimation_CVPR_2020_paper.html)：分别提供轻量恢复块和无需显式光流的时序建模参考；当前版本优先可审计的安全 gate，未引入未经校准的光流或残差重建。

## 6. 仍需补齐的生产验证

- 采集同一 sensor/曝光下的 clean 长曝光或多帧 burst 参考，再报告 PSNR、SSIM、RAW 梯度和颜色误差。
- 增加多个 ISO、曝光、相机运动和遮挡场景；当前两组序列不足以证明泛化。
- 若进入端侧，先导出 ONNX/TensorRT 并测量 tile/整帧延迟、显存和 BPU 算子覆盖；本交付只验证 PyTorch 原型和离线视频。
- 生产接入前保留硬回退和 gate 监控，任何阈值修改都应重新跑 `evaluate`、`stability` 和人工视频复核。
