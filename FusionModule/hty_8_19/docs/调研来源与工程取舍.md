# 调研来源与工程取舍

本文档只记录实际查阅并影响方案决策的来源。公开论文的实验结论不等于公司数据上的结论。

| 来源 | 对本项目的启发 | 未直接照搬的原因 |
|---|---|---|
| [CRVD / RViDeNet](https://openaccess.thecvf.com/content_CVPR_2020/html/Yue_Supervised_Raw_Video_Denoising_With_a_Benchmark_Dataset_on_Dynamic_CVPR_2020_paper.html) | 真实 RAW 视频需要明确的噪声/干净参考和动态场景 benchmark | 公司数据没有 clean GT |
| [RViDeformer](https://arxiv.org/abs/2305.00767) | RAW 时空注意力和跨帧建模方向 | 两组短序列和端侧约束不支持直接迁移大模型 |
| [UDVD](https://openaccess.thecvf.com/content/ICCV2021/html/Sheth_Unsupervised_Deep_Video_Denoising_ICCV_2021_paper.html) | 无 GT 场景可用自监督，但需明确噪声假设 | 当前数据不足以证明独立噪声观测 |
| [Neighbor2Neighbor](https://openaccess.thecvf.com/content/CVPR2021/html/Huang_Neighbor2Neighbor_Self-Supervised_Denoising_From_Single_Noisy_Images_CVPR_2021_paper.html) | 邻域自监督的适用条件与风险 | 不能把同一 RAW 奇偶拆分直接称为 Noise2Noise |
| [AIM 2025 challenge](https://openaccess.thecvf.com/content/ICCV2025W/AIM/html/Yakovenko_AIM_2025_Low-light_RAW_Video_Denoising_Challenge_Dataset_Methods_and_ICCVW_2025_paper.html) | 多 sensor、多照度、运动边界是泛化验证重点 | 当前交付只做公司数据可行性验证 |
| [NAFNet](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/3043_ECCV_2022_paper.php) | 轻量残差恢复块的工程参考 | 最终网络只预测安全 gate，不输出自由残差 |
| [FastDVDnet](https://openaccess.thecvf.com/content_CVPR_2020/html/Tassano_FastDVDnet_Towards_Real-Time_Video_Denoising_Without_Flow_Estimation_CVPR_2020_paper.html) | 无显式光流的轻量时序建模思路 | 当前优先硬安全回退和可审计性 |

最终选择“安全 gate + 2DNR 锚点 + 3DNR 候选”的原因不是它已经证明了全局最优，而是它在没有 clean GT 的现实条件下能把最危险的错误（运动拖影）约束到可检查的硬性质，并允许逐步增加数据和更强的对齐模块。
