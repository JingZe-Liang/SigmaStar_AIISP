# A12 固定样本与周期刷新的成对实验协议（2026-10-30）

本轮结果与核验入口见 [成对实验结果](A12_PAIRED_SAMPLING_RESULT_2026-10-30.md)。采样刷新带来部分重建收益，刷新组 model 的原生 PSNR 超过 A3；但 EMA 仍有原生静态回退，两类权重均未解决局部运动损失，默认模型继续保留 A3。

用户已确认推进本轮对照，并在 4090 被其他任务占用时明确选择空闲的 RTX 3090。训练和新评估统一使用经启动前核验的 3090。发生 OOM 立即停止并报告，不自动重试、降配或切换显卡。A3 默认权重和既有数据保持不变。

GPU 子进程设置 `CUDA_VISIBLE_DEVICES=GPU-07a5046e-9b56-8557-3845-d6cca9ea0497`，仅暴露这张物理 3090，因此配置中的 `cuda:0` 指向 3090；不能脱离该环境设置直接按主机默认序号启动。

## 科学问题与预算

检验在同一来源及增益日程下，第二周期刷新裁块、真实时窗和合成噪声，是否优于重复固定样本。本轮不等于原 A3 采样器的完整复现，也不单独分离裁块、时窗、噪声各自的作用。

从 A3 step-5000 EMA 初始化模型和 EMA，新建 Adam。公共阶段训练 512 步，之后两个分支分别恢复同一公共检查点的模型、EMA、Adam、Python/NumPy/PyTorch CPU/CUDA 随机状态，各训练 512 步，均达到累计 1024 步。总计 1536 次正式更新；检查点恢复验证使用独立短运行，不计作正式结果。

| 项目 | 固定组 | 刷新组 |
| --- | --- | --- |
| 首周期 | 两组共享相同的 512 步训练 | 共用左侧检查点 |
| 第二周期 | 重复首周期裁块、时窗、噪声 | 刷新裁块、时窗、噪声 |
| 来源及增益顺序 | 重复冻结的 512 项 source/record/gain 日程 | 与固定组逐步相同 |
| 真实与合成比例 | 每周期 256/256，交错 | 相同 |
| 监督、模型及损失 | 原 A3 静态目标与掩码 | 相同 |

FP32、batch 1、8 帧、64×64 packed、学习率 1e-5，梯度/高通损失权重 0.1/0.1，EMA decay=0.999，每 128 步保存。真实 1000x 继续留出。配置入口为 `configs/a12_paired_sampling_20261030.json`。

## 启动前核验

CPU 实际读取两个模式的完整 1024 样本计划，记录计划与张量哈希、来源/增益日程、有效覆盖、空掩码、有限值及输入范围。核验首周期完全一致、固定组重复首周期、刷新组改变采样且不改变来源/增益。空掩码必须导致审计失败，不静默跳过；低覆盖只记录，不在本轮加入筛样消融。

首次完整审计已发现刷新组索引 590、808、814 的真实裁块监督掩码全空；固定组无空掩码，其他协议检查通过。正式训练前对这三个位置离线生成确定性替代裁块及真实时窗，固定来源、记录和增益，以首个非空候选为准，最多尝试 64 次。记录失败计划、候选随机种子、有效覆盖和最终张量哈希，并冻结替代计划文件；其他低覆盖非空样本不变。替代后重新完整审计，正式训练严格读取审计通过的计划，不做运行时自动重采样。本轮结论对应这一明确的非空监督约束。

替代后的完整审计已通过，文件为 `artifacts/a12_paired_audit_v2_20261030/audit.json`，SHA-256 为 `cad9e3589f44d85d268084d808896186c6943f2541c98e111d178fac5d90ad1a`。三个位置均采用第一个候选，替代后的有效比例分别为 93.0176%、99.9756%、59.8145%。两组全部样本最低有效比例仍为 0.048828%，低覆盖问题没有在本轮解决。相关新旧测试共 66 项通过。

独立验证同一训练路径的两步连续更新与一步保存后恢复一步更新。保留逐参数、EMA、Adam、随机状态和损失的比较证据；验证角色不得作为正式分支的父检查点。正式分叉只允许经过身份校验的 shared step-512，禁止跨分支恢复或放宽其他训练配置检查。

GPU 小步检查未发生 OOM，但原端到端严格容差（rtol=1e-5、atol=1e-8）未通过，失败记录保留。直接核对恢复起点时，model、EMA、Adam、RNG 与源检查点的摘要全部逐位一致。补充同种子连续两步重复后，模型参数相对 L2 差异为 2.5587e-8，恢复两步与连续两步为 2.8550e-8；第二步损失差分别为 2.7940e-9、2.3283e-9。两种比较的最终 RNG 均逐位一致。当前按恢复起点完全一致的探索性实验继续，正式分叉再次核对两个起点；不声称 GPU 端到端位级复现，也不把两步诊断当作 1024 步数值漂移的上界。

完整检查见 `artifacts/a12_paired_work_20261030/gpu_resume_repeatability_comparison.json`；原失败门槛见同目录 `gpu_resume_verification_status.json`。当前 PyTorch 安装的确定性 API 文档明确列出部分 CUDA 反向运算的限制；通用说明见 [PyTorch 确定性算法文档](https://docs.pytorch.org/docs/stable/generated/torch.use_deterministic_algorithms.html)。本轮保留原模型与损失的运算定义。

## 固定评估与解释

A3 EMA、shared step-512 的 model/EMA、fixed 和 refresh step-1024 的 model/EMA 均运行同设备、FP32、tile_batch=1 推理。EMA 是主要候选，model 用于诊断短程 EMA 滞后；不根据结果临时切换主权重。

复用冻结的 12 组受控探针，记录各区域重建、高通、梯度和时序差分误差。MIS20S1 native 1000x 使用三个独立八帧窗口 0..7、96..103、192..199，分别推理及评分，不能拼接为连续视频；记录重建、平坦区域残差、时序 MAD 和高频幅度比。新缓存采用 FP32，双方保持相同参考、归一化、掩码和存储精度。

固定组、刷新组和 A3 三方同时比较。相对另一分支的改善不等于超过 A3；高频幅度比或更低时序 MAD 也不能独立证明细节保真。没有预先验证的部署阈值，本轮不自动晋级默认模型。

受控探针来自训练参考，native 参考包含被评测帧，全部属于开发诊断。若候选显示有意义且兼顾静态与运动的改善，再展开跨传感器固定区域及真实动态视觉检查；否则保留 A3，记录本轮结论，随后将动态监督作为独立实验变量。单种子两周期仅用于筛方向，不构成采样有效性或泛化的最终证据。
