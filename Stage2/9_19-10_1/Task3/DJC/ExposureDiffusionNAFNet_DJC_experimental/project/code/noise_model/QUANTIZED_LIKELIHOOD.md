# 第一版可求导 RAW 观测似然

## 结论

现在已经有一版可以进入 **R1 单帧后验采样消融**的观测模型，但它的适用范围必须限定为：MIS20S1、已标定增益、当前暗帧条件，以及“共享帧/行列噪声先边缘化为每像素方差”的近似。它已经不再只是暗帧生成器：对 DN 观测给出包含量化区间概率的可微 `log p(y|x)`，并通过 40/10 暗帧留出检查。

2026-09-28 重新检查时发现旧实现把 `torch.special.ndtr`（已是标准正态 CDF）又额外除以了 `sqrt(2)`。这会错误放宽 ADC 区间；在 `lambda=100` 的检查点，精确 Poisson 和高计数近似曾相差约 `0.34 nats/pixel`。现已修正、重新拟合九档参数、重新选择混合分量并重跑本节全部数值结果；旧表和旧 `selfcheck.json` 不再作为证据。

这还不是最终传感器似然。共享行列偏置的空间相关性暂时被边缘化，散粒系数仍受 48 DN 最低信号和曝光不匹配限制；因此 R1 必须先做固定先验、固定似然的可控消融，不能直接进入无 GT E/M。

## 模型

对黑电平扣除后的线性信号 `x` 和观测 DN `y`，实现的是

\[
y = d + K n + e, \qquad n\sim\operatorname{Poisson}(x/K),
\]

其中 `d` 是多帧暗场分解得到的固定图，`e` 是由暗帧像素残差拟合的 1/3/5 分量高斯混合，并把已估计的帧级、行级、列级方差并入每通道边缘方差。对量化 RAW 码值使用整个 ADC 区间的概率：

\[
p(y\mid x)=\sum_n \operatorname{Poisson}(n;x/K)\sum_j\pi_j
\left[\Phi\left(\frac{y+q/2-d-Kn-\mu_j}{\sigma_j}\right)-
\Phi\left(\frac{y-q/2-d-Kn-\mu_j}{\sigma_j}\right)\right].
\]

`q=2 DN` 仅用于当前已验证的暗帧码格；有光观测暂用 `q=1 DN`，不把暗帧奇偶码格强加到有光像素。代码在 [`quantized_likelihood.py`](quantized_likelihood.py)，拟合在 [`fit_quantized_likelihood.py`](fit_quantized_likelihood.py)。

## 拟合与留出

每档 50 张暗帧按时间分成：0–29 帧选择混合分量，30–39 帧在 1/3/5 个分量中选 NLL 最低者，40–49 帧只作最终留出。暗帧没有信号，所以这里的 NLL 是 `x=0` 下对量化暗码值的条件 NLL；它验证的是暗残差似然，不验证散粒斜率。

| 增益 | 选中分量 | 内部 NLL (nats/pixel) | 最终留出 NLL | 留出−内部 |
|---:|---:|---:|---:|---:|
| 100 | 5 | 0.9347 | 0.9314 | −0.0032 |
| 200 | 1 | 1.3365 | 1.3342 | −0.0022 |
| 400 | 3 | 1.8635 | 1.8635 | +0.0001 |
| 800 | 1 | 2.4425 | 2.4397 | −0.0029 |
| 1600 | 5 | 1.4201 | 1.4206 | +0.0004 |
| 3200 | 5 | 1.9730 | 1.9680 | −0.0049 |
| 6400 | 3 | 2.5655 | 2.5671 | +0.0016 |
| 12800 | 3 | 3.1394 | 3.1365 | −0.0029 |
| 25600 | 3 | 3.7126 | 3.7083 | −0.0042 |

内部与最终留出 NLL 的差异均约 `0.004 nats/pixel` 以内，说明在这 50 张同条件暗帧中没有发现明显的时间段失配。NLL 的绝对值不应跨增益比较“谁更好”，因为各档噪声尺度和量化分辨率不同；模型选择只在同一增益内比较。

## 数值验收

- 28 项项目测试通过；包括容器低位检查、12-bit DN 往返、暗帧量化似然的有限梯度、有限差分梯度、零信号量化概率归一性、下限/饱和尾部概率，以及高计数 Gaussian 分支相对精确 Poisson 求和的误差检查。
- `torch.autograd` 梯度和有限差分在固定参数样例上相符；没有 NaN/Inf。
- 量化似然使用 CDF 区间概率，不把离散 RAW 码值当作连续密度点值。
- 用对应暗场采样器生成 2 张暗帧，再用量化似然回评分；九档生成样本和真实留出 NLL 的绝对差为 `0.0028/0.0049/0.0071/0.0091/0.0238/0.0077/0.0091/0.0037/0.0051` nats/pixel（增益从 100 到 25600）。该闭环只证明生成器和边缘似然内部一致，不是对真实传感器的额外独立验证；完整结果在 `runs/noise/quantized_likelihood/selfcheck.json`。

## 还没有通过的部分

1. 共享帧级、行级、列级变量目前被边缘化为每像素方差，不能表达其联合空间相关性。暗场合成器仍应负责生成这些相关结构。
2. 散粒系数来自静态色卡的重复帧差分。彩色曝光范围为 83,317–326 µs，参与检验的最小扣黑信号为 48 DN；12800/25600 的 K 仍标为 provisional。具体截距策略与结果见 [`TWO_SHOTS_CVPR2026.md`](TWO_SHOTS_CVPR2026.md)。
3. 量化步长 `q=1` 的有光模型尚未由真实极暗场景验证；`q=2` 只对当前暗帧条件有证据。
4. 尚未用该似然做 R1 后验重建，因此尚无 PSNR/SSIM、伪纹理、色偏或真实场景结构保持结果。

## 下一阶段入口

先做固定先验、固定该似然的 R1 合成实验：用 H5 中明确的 `clean` 作为近似参考，按当前 K 和暗场模型生成 `q=1` 有光观测；在合成留出集上检查后验是否能恢复结构、是否出现数值不稳定。然后再用 `04_Sigmastar_7_30` 中按整条流划分的 MIS20S1 场景做无 GT 开发检查。只有 R1 在合成集和真实开发片段都不退化，才继续 E/M；不要在似然尚未通过前做 R2/R3。

```bash
/opt/miniconda3/envs/dl/bin/python -m noise_model.fit_quantized_likelihood \
  --calibration-root ../Data/Company_Dataset/dataset/04_Sigmastar_7_30/mis20s1_calibrationdata \
  --output runs/noise/quantized_likelihood \
  --shot-calibration runs/noise/two_shots_cvpr2026/calibration.json
```

输出包括九档 `.npz` 参数、`calibration.json` 和每档内部选择／最终留出 NLL。所有参数单位均为有效 12-bit DN；容器换算只由 [`raw_io.py`](raw_io.py) 负责。
