# MIS20S1 多帧暗噪声建模：同条件留出对照

## 结论

对现有 **83,317 µs** 暗帧，40 帧拟合的多帧分解在增益 **1600–25600** 上比单帧频谱基线更准确地保留稳定固定图案，并更接近留出帧的时间方差和径向频谱；但它的合并像素直方图距离略大。增益 **100–400** 没有稳定优势，暂保留较简单的单帧模型。增益 **800** 的帧级偏移得到表达，但两种模型的合并分布距离相近；还不能据此选定最终模型。

这是**暗场候选合成器**的比较，不是极暗有光图像、不同曝光或最终降噪效果的验收。

## 方法与论文关系

[Feng 等，*Learning Physics-Informed Noise Models from Dark Frames for Low-Light Raw Image Denoising*, IEEE TPAMI 2026](https://pubmed.ncbi.nlm.nih.gov/41525585/) 的 PNNP 将暗噪声分成帧级、行列带状和像素级分量，并用物理先验处理可解释的部分。本项目实现了这种**物理引导分解**：多帧平均估计固定暗图，按有限样本噪声地板收缩高频图案，估计四 Bayer 通道联动的帧偏移与行/列协方差。[作者仓库](https://github.com/fenghansen/PNNP)明确说明 PNNP 噪声代理的训练代码未公开；这里**没有复现**其 1×1 神经代理和可微分布损失。

剩余像素随机项使用 [Lu 等，*2-Shots in the Dark*, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Lu_2-Shots_in_the_Dark_Low-Light_Denoising_with_Minimal_Data_Acquisition_CVPR_2026_paper.pdf) 的频谱幅值与秩直方图交替采样。把幅值改为 40 帧平均功率、把目标直方图改为多帧残差池，并在最后再做一次边缘分布投影，均是**本项目适配**，不是两篇论文原文的端到端算法。帧偏移经验抽样、固定图案的有限样本收缩和 ADC 奇偶码格处理也是本项目适配。完整实现见 [`pnnp_decomposition.py`](pnnp_decomposition.py)。

## 数据划分和指标

九档增益各有 50 张相同标称曝光的 MIS20S1 暗帧。多帧模型只用第 0–39 帧；单帧 CVPR 基线只用第 0 帧；两者都与第 40–49 帧比较，每档各生成 10 张合成帧。下表均为四个 Bayer 通道的平均：

- **固定图案 RMSE**：模型固定暗图与 10 张真实留出帧均值图之差，先移除每通道全局均值再求空间 RMSE；因此不把帧级均值误差混进去。
- **时间标准差误差**：每像素跨帧标准差的空间 RMS，相对真实留出组的百分比；正数表示合成过强。
- **频谱误差**：留出与合成随机残差六段径向功率谱比值的平均绝对对数，乘以 100；不是去噪 PSNR。
- **W1**：每通道在相同 1/8 空间网格抽样、合并 10 帧的原始 RAW 码值 Wasserstein 距离，单位 DN。
- **帧均值 SD**：10 张帧的空间均值标准差。这里用总体标准差，且四通道平均。

每格 `多帧 / 单帧`；帧均值 SD 列为 `真实 / 多帧 / 单帧`。

|---:|---:|---:|---:|---:|---:|
| 100 | 0.390 / 0.391 | +0.07 / +0.33 | 4.29 / 2.70 | 0.017 / 0.020 | 0.004 / 0.000 / 0.000 |
| 200 | 0.587 / 0.587 | +0.24 / +0.29 | 2.62 / 2.02 | 0.012 / 0.013 | 0.004 / 0.001 / 0.000 |
| 400 | 1.001 / 1.004 | +0.90 / +0.38 | 1.63 / 1.05 | 0.030 / 0.020 | 0.008 / 0.007 / 0.000 |
| 800 | 1.783 / 1.788 | +0.49 / −0.16 | 0.88 / 0.93 | 0.328 / 0.316 | 0.457 / 0.490 / 0.000 |
| 1600 | 0.686 / 0.860 | +2.93 / +4.31 | 4.55 / 7.15 | 0.028 / 0.017 | 0.007 / 0.006 / 0.000 |
| 3200 | 1.196 / 1.598 | +1.42 / +5.51 | 2.41 / 9.73 | 0.035 / 0.032 | 0.009 / 0.010 / 0.000 |
| 6400 | 2.173 / 3.006 | +0.37 / +6.24 | 0.66 / 10.95 | 0.067 / 0.044 | 0.013 / 0.021 / 0.000 |
| 12800 | 3.862 / 5.397 | +0.10 / +6.50 | 0.41 / 11.41 | 0.129 / 0.095 | 0.019 / 0.035 / 0.000 |

高增益固定图案 RMSE 的多帧改善约为 20%–29%；25600 档真实时间标准差约 19.692 DN，按独立抽样近似计算，40 帧训练均值与 10 帧留出均值之差的误差量级为 `19.692 × √(1/40 + 1/10) ≈ 6.96 DN`，接近观测的 6.858 DN。这个近似不是严格置信区间，但说明继续压低该指标需要更多真实帧。W1 在高增益反而增加 0.011–0.042 DN；不能声称多帧模型全面胜出。独立像素池消融结果也保存在 JSON 中，供检查频谱采样器带来的差异。

### 同条件“真实对真实”参照

为了给 W1 一个抽样波动参照，把训练区间的 0–9、10–19、20–29、30–39 帧分别与留出的 40–49 帧比较；空间抽样及四通道平均方式与上表相同。下表是四次比较的**最小–最大值**，不是置信区间，也不是预先设定的验收阈值。前 40 帧已参与多帧模型拟合，因此此分析只用于探索性量级判断，不能替代新的独立测试序列。

| 增益 | 真实 10 帧 vs 真实 10 帧 W1 范围 (DN) | 多帧合成 W1 | 单帧合成 W1 |
|---:|---:|---:|---:|
| 100 | 0.008–0.012 | 0.017 | 0.020 |
| 200 | 0.010–0.013 | 0.012 | 0.013 |
| 400 | 0.015–0.020 | 0.030 | 0.020 |
| 800 | 0.035–0.318 | 0.328 | 0.316 |
| 1600 | 0.013–0.017 | 0.028 | 0.017 |
| 3200 | 0.020–0.024 | 0.035 | 0.032 |
| 6400 | 0.033–0.048 | 0.067 | 0.044 |
| 12800 | 0.051–0.147 | 0.129 | 0.095 |
| 25600 | 0.128–0.280 | 0.236 | 0.194 |

例如 6400 档，多帧模型的时间标准差和频谱明显改善，但 W1 `0.067 DN` 超过这四组真实数据之间的 `0.033–0.048 DN`；单帧基线的 `0.044 DN` 落在该范围内。因此“高增益多帧更好”只适用于固定图案和相关频谱等指标，**不能解读为整体噪声分布已经合格**。800/12800/25600 档的真实对真实范围较宽，主要提醒十帧和罕见码格状态不足以稳定判定边缘分布。

正式判定不能只看平均频谱或单个 W1。下一轮应先固定未参与调参的整段数据，对每档、每个适用曝光分别报告：固定图案误差、时间方差、行/列及二维频谱、分位数尾部、四 CFA 通道的码值分布和帧级状态；并把合成对真实的偏差与多段**独立真实对真实**比较。只有偏差在预先定义的抽样波动范围内、且下游 R0 在真实开发片段不退化，才可将对应条件的模型标为通过。目前没有足够独立段落建立可靠的 95% 范围，也没有预先登记的统一数值阈值，因此本报告只能给出分项优劣，不能给出总体验收通过。

## RAW 码格发现及旧结论修正

这批暗帧的有效码值间隔为 **2 DN**。增益 100、1600 的训练帧均为奇数码；200、400、3200、6400 均为偶数码；800 档前 40 帧有 15 张偶数、25 张奇数；12800 为 39/1；25600 为 35/5。留出的最后 10 帧在 800 档为 3/7，而 12800 和 25600 均是 10/0。比较时，单帧模型按第 0 帧的码格量化，多帧模型根据训练帧抽样码格，并在加完随机项后量化。之前 [`ONE_FRAME_DARK_VALIDATION.md`](ONE_FRAME_DARK_VALIDATION.md) 的“ADC 取整后分布距离”实际按 **1 DN** 取整，不能当成传感器码值的 W1；本报告中相同 2 DN 规则下的 W1 取代该列。

增益 800 的多帧模型能恢复约 0.49 DN 的帧均值波动，接近真实留出 0.457 DN。12800/25600 档训练集中稀有的奇数码状态在最后 10 帧未出现，所以多帧模型的帧均值 SD 在 25600 档达到 0.299 DN，而留出帧仅 0.033 DN；这主要暴露了**罕见状态概率估计和十帧检验的不确定性**。若假设独立且状态概率等于训练频率，连续 10 帧不见奇数码的概率在 12800 档约为 `(39/40)^10 = 0.776`，在 25600 档约为 `(35/40)^10 = 0.263`，都不罕见。不能仅凭这十帧断言该状态不存在，也不能直接把训练频率当成最终概率。

## 当前使用建议与所缺数据

增益 100–400：保留单帧 CVPR 合成基线；1600–25600：将此多帧分解作为**更有根据的暗场候选**，同时保留单帧对照；800：两者并行，优先复核帧级码格与偏移。现有暗帧全部为 83,317 µs，而部分有光校准帧曝光远短于此，所以这套参数**不能直接宣称适用于极暗目标曝光**。散粒系数来自另一个彩色重复帧校准，特别是 12800/25600 仍为暂定值；`sample_observation` 只提供“Poisson 散粒项 + 该暗模型”的暂定合成接口。有光输出仅在 `[0,4095] DN` 内按 1 DN 取整，**不沿用暗帧的固定奇偶码格**；这不是已经由数据确认的信号相关 ADC 模型，不能据此声称有光分布通过验证。

现有执行计划注明暂不能补拍；因此先用这批数据做**受限的 R0/R1 合成对照**，按不同时间块重复检验并记录不确定性，不能把同曝光暗场匹配外推成目标曝光匹配。若采集条件后来允许，最需要的是**同一 MIS20S1、目标增益和曝光、记录温度**的多段独立暗帧序列；高增益尤其要有足够帧数估计稀有 ADC 状态。另需每档多个照度的重复平场 RAW，以独立验证散粒系数和信号相关方差。Apple clean RAW 与 MIS20S1 的相机响应不同，作为训练底图前仍需跨传感器线性响应映射验证。当前本地拟合和暗场对照无需租服务器；后续完整扩散模型重训再按显存、数据量和目标训练时长评估算力。现有计划认为单张 3090/4090/5080 可用于训练，尚未据正式配置实测显存和耗时。

本留出组在迭代排查固定图案收缩和码格时已被查看，因此是**探索性留出**，不能冒充完全未触碰的最终测试集。新采的独立序列或预先固定方案的交叉验证才能给出确认性结论。
